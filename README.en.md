# RongMC Welcome (Legacy)

[简体中文](./README.md) · English


Adds a first-launch welcome page and optional mod switches to a client pack. Pack maintainers can configure a welcome message. Players can select optional mods in game and apply the changes by restarting. Completion is stored locally.

## In game

On the title screen, complete the welcome and open Optional Mods to manage JARs supplied by the pack. This project is for packs that ship the legacy welcome page. See [RongMC Client](https://github.com/OpenRongMC/RongMC-Client) for current device tiers.

## Installation

Download **v1.0.0+26.3** from [GitHub Releases](https://github.com/OpenRongMC/RongMC-Welcome/releases/tag/v1.0.0%2B26.3) for Minecraft Java **26.3** on **Fabric** with **Java 25**. Dependencies include [Fabric API](https://modrinth.com/mod/fabric-api). Place the release JAR in the instance’s `mods/` directory. Use it with a client pack that explicitly ships this legacy welcome module. RongMC Client supplies the five-tier device setup used by the current low-spec pack.
