# RongMC Welcome

建筑服客户端用的**首次欢迎页**与**可选模组开关**。

## 功能

- 主菜单首次进入弹出欢迎说明（文案可配置）。
- 「可选模组」界面：按目录启用/禁用客户端可选 jar，改完可提示重启客户端使生效。
- 完成欢迎后写入本地配置，避免每次都弹。

## 使用

1. 将本模组放入客户端 `mods/`。
2. 启动后按界面提示阅读欢迎页，需要时打开可选模组列表。
3. 配置位于游戏配置目录（见源码 `WelcomeConfig`）。

## 说明

- 纯客户端向；不负责服务端玩法。
- 可选模组列表内容来自内置/配置目录，乱删 jar 可能导致整合包不完整。
