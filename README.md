# RongMC 旧版欢迎页

简体中文 · [English](./README.en.md)


为客户端整合包添加首次欢迎页和可选模组开关。维护者可以配置欢迎文案，玩家可以在界面选择可选模组，重启游戏后应用。欢迎完成状态会保存在本地。

## 使用

在标题画面完成欢迎后，可选模组界面会管理整合包指定目录中的 JAR。此项目用于带旧欢迎页的客户端包。当前低配包的设备档位见 [RongMC Client](https://github.com/OpenRongMC/RongMC-Client)。

## 安装

在 [GitHub Releases](https://github.com/OpenRongMC/RongMC-Welcome/releases/tag/v1.0.0%2B26.3) 下载 **v1.0.0+26.3**。使用 Minecraft Java **26.3**、**Fabric** 和 **Java 25**。 依赖 [Fabric API](https://modrinth.com/mod/fabric-api)。 将发行 JAR 放进实例的 `mods/` 目录。 用于明确配套此旧欢迎模组的客户端实例。当前 RongMC 低配整合包的五档设备选择由 RongMC Client 提供。
